The sandbox has no network, and no imports except `asyncio`, `pathlib` and the host functions below. It has the filesystem listed under Filesystem below: read and write it with `open()` and `pathlib.Path`. File operations are synchronous (never `await` them) and work on whole files; read lines with `f.read().splitlines()`, not `for line in f`. A failed file operation raises an `OSError` subclass (`FileNotFoundError`, `FileExistsError`, `IsADirectoryError`, `NotADirectoryError`, `PermissionError`) whose message names the path; it has no `errno`.
