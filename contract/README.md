# The contract

The files every harness SDK is tested against, so an SDK is checked against what the protocol
says rather than against another SDK's internals. Python generates each of them for now, and a
test fails while a committed file differs from what Python writes.

| File | What it is | Generated by |
| --- | --- | --- |
| `protocol.schema.json` | The event stream's wire types: every event an agent publishes. The TypeScript client's `protocol.ts` is generated from it. | `temporal-agent-harness schema --protocol` |
| `registry.schema.json` | The `agents.toml` format that `serve` reads. Keys it does not name are ignored, so an SDK can add its own. | `temporal-agent-harness schema --registry` |

After a change that alters one, rewrite it and commit the result:

```bash
bazel run //contract:protocol_update
bazel run //contract:registry_update
```

`bazel test //contract/...` fails while either is out of date. A change to `protocol.schema.json`
also needs `bazel run //typescript/packages/client/src:protocol_codegen_update`.
