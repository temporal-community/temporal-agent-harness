# Meeting notes

1. Read the template at `/skills/meeting-notes/template.md`.
2. Fill it in from what the user gave you. Keep decisions and action items short; every action
   item has an owner. Leave a section's placeholder line as `- None` when nothing fits.
3. Write the notes to `/workspace/meeting-notes.md` and reply with the action items.
